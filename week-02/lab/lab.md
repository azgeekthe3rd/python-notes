## Task 1 — Indexing + .upper() + f‑string

Create a list of five fruits, ```['Apple', 'Banana', 'Cherry', 'Orange', 'Grapes']``` — and use the first element in this sentence: **“The first fruit in the basket is…”**, making sure it appears in uppercase.

**Expected output**

```
The first fruit in the basket is APPLE
```

---

## Task 2 — .append() + .insert()

Build a list with the elements ```['Cat', 'Dog', 'Rabbit', 'Horse', 'Elephant']```. Show the difference between .append() and .insert(). Append giraffe to the end of the list, and insert panda as the third element.

**Expected output**

```
['Cat', 'Dog', 'Rabbit', 'Panda', 'Horse', 'Elephant', 'Giraffe']
```

---

## Task 3 — del, .pop(), .remove()

Create a list with the following colors: `['Red', 'Blue', 'Green', 'Yellow', 'Purple']`. **Delete** the fourth element, **pop** the second element, then **remove** the colour Green, and then print the original list, the remaining colors, and the color that was popped.

**Expected output**

```
The original colors are: ['Red', 'Blue', 'Green', 'Yellow', 'Purple']
The remaining colors are: ['Red', 'Purple']
The second color that was popped is: Blue
```

---

## Task 4 — .sort(), sort(reverse=True), sorted()

Make a list named `"countries"`: `['Japan', 'Canada', 'Brazil', 'France', 'Egypt']`. Use the `sorted` function to sort the list in ascending order and print the result. Then use the `sort` method to sort the list in place in ascending order and print the result. Finally, use the `sort` method with the `reverse` parameter set to `True` to sort the list in descending order and print the result.


**Expected output**

```
['Brazil', 'Canada', 'Egypt', 'France', 'Japan']
['Brazil', 'Canada', 'Egypt', 'France', 'Japan']
['Japan', 'France', 'Egypt', 'Canada', 'Brazil']
```

---

## Task 5 — .reverse() + len()


Create a list of drinks named: ``"drinks"`` with the following items: "Water", "Juice", "Tea", "Coffee", "Milk". Use the ``.reverse()`` method to reverse the order of the list and print the reversed list. Finally, use the ``len()`` function to print the number of items in the list.

**Expected output**

```
['Milk', 'Coffee', 'Tea', 'Juice', 'Water']
5
```
